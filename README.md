# ibooks

这是一个用于整理和存放小说 / 电子书文件的仓库。

仓库里的文件可能会比较多、体积也可能越来越大。如果你只是想查看或下载其中一部分内容，不建议直接把整个仓库 clone 到本地。

## 推荐使用 RepoExplorer

如果不想一次性拉取全部小说，可以使用我的桌面工具 **RepoExplorer**：

https://github.com/gralliry/RepoExplorer

RepoExplorer 可以像资源管理器一样打开 GitHub 仓库：

- 浏览仓库目录
- 搜索文件
- 只下载需要的文件或文件夹
- 不需要 clone 整个仓库
- 支持按需打开、下载和管理文件

使用方式：

1. 打开 RepoExplorer
2. 点击“打开仓库”
3. 输入：

```text
gralliry/ibooks
```

然后就可以按需浏览和下载文件。
